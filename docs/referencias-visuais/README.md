## Como aplicar ao projeto

- Use as capturas como referência **estrutural e funcional**, não como cópia literal de identidade visual.
- A identidade oficial do PanelAI usa um ícone original de panela verde-sálvia, fundo off-white, cartões claros e cor principal #789582.
- No desktop, privilegie calendário semanal com vários dias simultâneos.
- No celular, use navegação por dia, cartões verticais e controles touch adequados à compra no supermercado.
- Integre receitas, porções, lista semanal e estoque para calcular necessidades de compra sem duplicar ingredientes.
- Não publique as imagens na pasta public/ se forem apenas documentação de desenvolvimento.
